# Smart Traffic & Road Safety Analytics

An end-to-end computer vision system for traffic monitoring, vehicle analytics, and road safety analysis.

## Project Overview

This project uses computer vision and deep learning to analyze traffic images and videos.

The system is designed to:

* Detect vehicles and pedestrians
* Track objects across video frames
* Count vehicles
* Analyze traffic density
* Estimate vehicle speed
* Detect selected road-safety violations
* Evaluate computer vision model performance
* Expose inference functionality through an API
* Containerize the application with Docker
* Generate analytics for visualization and reporting
